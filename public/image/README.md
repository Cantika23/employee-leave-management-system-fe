# Folder Logo & Gambar

Simpan file logo login / branding di sini.

## Logo aplikasi

Letakkan file logo dengan nama:

```
logo.png
```

Path lengkap: `public/images/logo.png`

Komponen `Logo` akan otomatis memuat gambar ini di:
- Landing page (navbar & footer)
- Halaman login
- Sidebar dashboard

### Rekomendasi
- Format: PNG (transparan) atau SVG
- Ukuran ideal: 256×256 px atau lebih
- Rasio: 1:1 (persegi) agar rapi di avatar/icon

Jika file `logo.png` belum ada, UI menampilkan fallback teks **MK** (MITRAL KPI).
